# IPL Cricket Analytics

## Project Overview
This project analyzes IPL cricket data using Python, SQL, and visualization.

## Tech Stack
- Python (pandas, numpy, matplotlib)
- SQL
- Jupyter Notebook

## Folder Structure
- data/raw → raw datasets
- data/processed → cleaned data
- notebooks → analysis notebooks
- sql → SQL queries
- reports → charts & outputs
- dashboard → future dashboard

## Goal
Perform data analysis on IPL matches and generate insights.
